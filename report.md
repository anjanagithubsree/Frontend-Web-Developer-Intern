## 1. Introduction

As part of my internship at YuvaIntern, I completed the Week 1 task titled **“Transforming Wireframes into Static Web Pages.”**

The objective of this task was to understand how a visual website design can be implemented using HTML and CSS.

For this project, I developed a landing page for a fictional creative agency named CreativeStudio. The website presents the agency's services, introduces its design philosophy, and provides contact information for potential clients.

The design follows a modern and minimalist approach, incorporating a custom SVG logo, a cream-and-brown color palette, clean typography, and responsive layouts.

As a wireframe was not provided, I used a self-created visual reference to guide the implementation.

## 2. Objectives

The main objectives of this task were:

* To understand the process of converting a visual design into a static website.
* To create a structured web page using HTML5.
* To apply CSS3 for styling and layout design.
* To develop a unique logo for CreativeStudio.
* To use CSS Grid and Flexbox for arranging website elements.
* To implement responsive layouts for desktop, tablet, and mobile devices.
* To improve website appearance through colors, typography, spacing, and hover effects.
* To organize HTML and CSS code into separate files.

## 3. Project Description

CreativeStudio is a fictional creative agency website designed to showcase digital design services.

The landing page provides information about the agency and its services through a simple, professional interface.

The website consists of the following sections:

### 3.1 Header and Navigation

The header contains the CreativeStudio logo and navigation links for Home, Services, About, and Contact. The navigation links allow users to move to different sections of the page.

### 3.2 Hero Section

The hero section introduces CreativeStudio with the heading “We create digital experiences that inspire.”

It includes a brief description, a call-to-action button, and a decorative workspace illustration created using CSS.

### 3.3 Services Section

This section displays three services offered by the fictional agency:

* Web Design
* Graphic Design
* UI/UX Design

Each service is presented in a separate card containing an icon, number, title, and description.

### 3.4 About Section

The About section describes the studio's focus on creativity, simplicity, and user-friendly digital experiences.

A highlighted statistic card adds visual emphasis to the design.

### 3.5 Contact Section

The Contact section encourages visitors to discuss their projects with the agency. The contact button uses a `mailto:` link to open the visitor's default email application.

### 3.6 Footer

The footer includes the CreativeStudio logo, copyright information, and a Back to Top link.

## 4. Technologies Used

### HTML5

HTML5 was used to create the structure and content of the website.

Important elements include:

* `<header>` for the website header.
* `<nav>` for navigation links.
* `<main>` for the main content.
* `<section>` for different website sections.
* `<article>` for individual service cards.
* `<footer>` for footer information.
* `<a>` for navigation and call-to-action links.
* `<svg>` for the custom logo and service icons.

### CSS3

CSS3 was used to control the appearance and layout of the website.

The main concepts used include:

* CSS selectors and variables.
* Background colors and gradients.
* Typography and text styling.
* Margins, padding, and borders.
* Flexbox and CSS Grid.
* Hover effects and transitions.
* CSS transformations.
* Media queries for responsive design.
* Border radius and box shadows.

### Development Tool

Visual Studio Code was used to write and organize the HTML and CSS files. A web browser was used to view and review the website.

## 5. Unique Logo Design

A custom logo was developed for CreativeStudio using inline Scalable Vector Graphics (SVG).

The logo combines the letters C and S into a monogram and includes leaf-inspired details representing creativity and growth.

The brown color complements the website's overall theme. The logo appears in both the header and footer.

Using SVG allows the logo to scale without losing visual quality and eliminates the need for a separate logo image file.

## 6. Website Design and Styling

The website follows a clean and minimalist design approach.

The key design features include:

* A cream, white, and brown color palette.
* Clear typography and heading hierarchy.
* Consistent spacing between sections.
* Rounded service cards with subtle borders.
* A CSS-based workspace illustration.
* Simple icons representing services.
* Hover effects on buttons, cards, and the logo.
* A dark footer that contrasts with the lighter page sections.

These elements help create a visually consistent and professional landing page.

## 7. Responsive Web Design

Responsive design was implemented using CSS media queries.

**Desktop View:** The hero section displays text and illustration side by side. The three service cards appear in a single row.

**Tablet View:** The service cards adjust to two columns, and the layout spacing is modified to fit the available screen width.

**Mobile View:** The navigation is arranged vertically, the hero content is stacked, the service cards appear in a single column, and the footer elements are arranged vertically.

These adjustments help make the website easier to view on different screen sizes.

## 8. Project Structure

The project uses two separate files:

```text
CreativeStudio/
│
├── index.html
└── style.css
```

**index.html:** Contains the website structure, text content, navigation, SVG logo, and section elements.

**style.css:** Contains the styling rules, layout definitions, custom illustration styles, hover effects, and responsive media queries.

Separating HTML and CSS improves code organization and makes the website easier to maintain.
